### NOME DO PROJETO
Fizzbuzz
### DESCRIÇÃO
Fizz pra números múltiplos de 3, Buzz pra números múltiplos de 5, FizzBuzz pra números múltiplos de 3 e 5 e o próprio número se nenhuma das condições for verdadeira.
### LÓGICA UTILIZADA
O operador de módulo `%` serve para saber se a divisão entre dois números é exata, identificando os múltiplos. Já o `&&` é um operador lógico que verifica se ambas as condições apresentadas são verdadeiras simultaneamente antes de executar o código.
